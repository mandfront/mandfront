### 👩‍💻 Sobre mim

Desenvolvedora **Front-End Sênior** com quase 7 anos construindo aplicações web para produtos de grande escala em **atendimento omnichannel, seguros e serviços financeiros**.

- 🏗️ Arquitetura de front-end, **micro-frontends** e design systems com **Storybook**
- 🧪 Testes unitários, de integração e e2e com **Jest, Testing Library e Cypress**
- ⚡ Performance, Core Web Vitals e SSR com **Next.js**
- 🤖 **IA e automação**: integrações com LLMs, bots, automações e APIs da Meta
- 🐍 **Python** e fundamentos de **segurança cibernética** (nível intermediário)
- 🤝 Code review e mentoria de devs em início de carreira
